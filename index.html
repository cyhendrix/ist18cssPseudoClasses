Pseudo-Class Reminder

Use the four link states in LVHA order. Each state needs its own CSS rule.

:linkStyles a link that has not been visited.

:visitedStyles a link that has already been opened.

:hoverStyles a link while the pointer is over it.

:activeStyles a link while it is being clicked.

Each rule needs a selector, opening brace, property and value, semicolon, and closing brace.
